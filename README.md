# Rep Coach

**Train with a plan.** A bring‑your‑own‑key AI strength coach.

- 🗓️ **Programme builder** — a weekly split for your goal, experience, equipment, schedule and limitations, with sets, rep ranges, rest and a form cue per exercise. Regenerate any time.
- 📝 **Set logging** — weight × reps per set with "last time" shown inline; wavy session progress; tap ⓘ for setup, execution and common mistakes.
- 🧠 **Coach review** — after each session: summary, highlights/PRs, per‑exercise progression with concrete next targets (e.g. "3×8 @ 62.5 kg"), recovery tip.
- 📊 **History & records** — sessions per week, lifetime volume trend, heaviest set per exercise.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
